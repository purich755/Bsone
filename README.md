# BSONE — демо главной страницы

Break dance studio «ONE», Казань, ул. Беломорская, 6. Концепция «КРУГ»: страница — сайфер, 12 раундов.

## Запуск

- Двойной клик по `index.html` — работает с диска (нужен интернет только для GSAP и Lenis с jsdelivr).
- Локальный сервер: `node tools/serve.mjs 8331` → http://localhost:8331/
- Деплой как статика: в корень кладутся `index.html`, `css/`, `js/`, `assets/` (папки `raw/`, `tools/`, `node_modules/` в `.vercelignore`).
  Vercel в РФ открывается не у всех — для клиента надёжнее GitHub Pages.

## Структура

```
index.html            разметка, 12 раундов
css/style.css         дизайн-система, секции, адаптив 1440/1024/768/390, reduced-motion
js/main.js            Lenis + ScrollTrigger, прелоадер, кольцо, FREEZE, табло, «Путь», раунды, меню, курсор
js/sampler.js         MPC-пэды, синтез звука на WebAudio (без файлов), дисплей с «печатью»
js/gallery.js         контактный лист + лайтбокс (FLIP, стрелки, свайп, колесо, Esc)
js/stickers.js        трофейная стена: «шлепок», drag с инерцией
assets/img/           все фото локально, WebP ≤ 300 КБ
assets/logo/          логотип (белый на прозрачном) и фавиконы
assets/fonts/         Dela Gothic One, Geologica, IBM Plex Mono (файлы Google Fonts, только latin+cyrillic)
tools/                сбор и самопроверка (см. ниже)
```

## Самопроверка (tools/)

| Скрипт | Что делает |
|---|---|
| `dump-tg.mjs`, `fetch-tg.mjs` | выкачка ленты t.me/s/break_dance_studio_one (2041 пост, 943 фото) |
| `dump-yandex.mjs`, `fetch-ya-photos.mjs` | карточка, галерея и отзывы Яндекс.Карт (122 фото в orig) |
| `build-assets.mjs` | все WebP сайта из raw/ по списку, подбор качества до ≤ 300 КБ |
| `gen-spot.mjs` | разметка контактного листа из манифеста (размеры не руками) |
| `build-map.mjs` | статичная тёмная карта района из тайлов OSM |
| `shots.mjs`, `shot-sheet.mjs` | сплошной проход скриншотами (1440/1024/768/390, `--reduced`, `--intro`) |
| `interact.mjs` | 21 проверка интерактива: кольцо, меню, раунды, пэды и звук, клавиши 1–8, лайтбокс, стикеры, «Путь» |
| `filecheck.mjs` | открытие через file:// |

Итог: Lighthouse десктоп 99 / 100 / 100 / 100, мобильный 95 / 100 / 100 / 100. Консоль чистая, горизонтального скролла нет ни на одной ширине.

## Чего не нашлось и чем заменено

- **Альбомы ВК** («Фотосессия учеников 2025» и турнирные) — недоступны без входа. Фото фотосессии частично есть на Яндексе (кадры в зелени и у баннера ONE) — они и стоят в «Пути» и контактном листе.
- **Кадры лагеря** — только из Telegram, максимум 800 px. Фон сцены CAMP растянут до 1600 px и спрятан под дуотон и зерно; в полном разрешении лучше взять оригиналы у студии.
- **Портрет тренера** — отдельной студийной съёмки нет; взят кадр ya113 (1920×2560, Иван в зале). Что это он — сверено с афишей судей «БРЕЙК СОЮЗ 2026» (Vanya One) и фото с грамотой Минспорта РТ.
- **Яндекс.Карта** — вместо iframe стоит своя тёмная схема (OSM) с красной меткой и кнопкой «Открыть в Яндекс Картах»: виджет Яндекса показывает рейтинг и звёзды, а их по брифу выводить нельзя.
- **Фото на пэдах сэмплера** — подобраны по смыслу из турнирных кадров; это не постановочные демонстрации конкретных элементов.

## Что уточнить у клиента

1. С какого возраста набор: 4 года (ВК) или 3 (Яндекс, в Telegram есть группа «начинашек 3–5 лет»)? Как делятся группы?
2. Часы: на Яндексе 16:00–21:00, в ВК — с 17:30. На сайте сейчас только «по вечерам».
3. Можно ли публиковать фото детей на сайте (на сайте — только то, что студия сама выложила).
4. Подтвердить портрет Ивана и как подписывать: «Иван», «Vanya One», полное имя?
5. Формулировки достижений: годы, точные названия соревнований, разряды. Откуда «ТОП-3 школ брейкинга Поволжья»?
6. BSONE CAMP: в канале — «10 ANNIVERSARY» в 2026 году и сроки 10–14 дней. Можно ли писать «10 лет лагерю»? Нужны оригиналы фото лагеря.
7. Пробное занятие: платное или бесплатное, нужна ли запись заранее?
8. Есть ли другие тренеры (в лагере работают Gekkon и Bgirl Luna)?
9. Актуальны ли хип-хоп, модерн, хореография, акробатика из карточки Яндекса — или только брейкинг?
10. Логотип в векторе.
11. Какой из входов на фото «Вход · ищите наклейку ONE» — настоящий вход в зал?

## Что сознательно не сделано (по брифу)

Нет цен, рейтинга и числа отзывов, афиш и дат, форм записи и оплаты, выдуманных фактов и имён детей. Цитаты родителей — дословно из отзывов на Яндексе, подпись — имя и инициал.
